# プラグイン開発ガイド (Plugin Development Guide)

## 1. 概要
Pakila における外部機能拡張・カスタムツールの追加は、物理隔離された Wasmtime サンドボックス環境（Wasm FFI）または Lean 4 モジュール型プラグインとして実装されます。

---

## 2. Wasm サンドボックス FFI 仕様

### 2.1. 物理境界構成
- **ネイティブ FFI (`src/native/kernels.c`)**: `-lwasmtime` ライブラリと直接リンクし、Wasm モジュールのロード、メモリ確保、関数呼び出しを行う C インターフェース。
- **Lean モジュール (`Pakila.Plugins.WasmLoader`, `Pakila.Core.Wasm`)**: C FFI を呼び出す安全な Lean 4 ラッパー。

### 2.2. プラグインの安全原則
- **メモリ隔離**: プラグインは自身の Wasm メモリ空間内でのみ動作し、Pakila のヒープメモリ領域に直接アクセスできません。
- **異常系の安全な検出**: プラグインがトラップ（クラッシュ、割り出し例外）を発生させた場合、`AppError.ExecutionError` にフォールバックしメインループは停止しません。

---

## 3. プラグインの追加手順

1. **Wasm モジュールのビルド**:
   C/C++/Rust 等でプラグインロジックを記述し、WebAssembly (`.wasm`) へコンパイルして `Plugins/` ディレクトリに配置します。

2. **Dispatcher への登録 (`Pakila.Plugins.Dispatcher`)**:
   並列アクションディスパッチャに新ツールのシグネチャとパース処理を追記します。

3. **テストの記述**:
   `test/` 配下にプラグインのユニットテストおよびシナリオテストを定義します。
