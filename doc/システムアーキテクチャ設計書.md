# システムアーキテクチャ設計書 (System Architecture Specification)

## 1. システム概要
`Pakila` は、形式検証済みエージェント基盤における最上位オーオーケストレータおよびインタラクティブ実行環境である。Wasmtime サンドボックス、マルチモーダル入力、並びに `Lyceum` / `nomos` / `LeanTensor` / `lbir` を統合し、型安全かつ防腐性の高い統合 LLM ワークスペースを提供する。

---

## 2. C4 アーキテクチャモデル

### 2.1. Level 1: システムコンテキスト (System Context)
```
+-----------------------------------------------------------------+
|                        Pakila アプリケーション                  |
|              (インタラクティブ UI / 実行エンジン)               |
+-----------------------------------------------------------------+
          |                                       |
          v (MCP & Generic LLM)                   v (形式検証・ガバナンス)
+-----------------------------------+   +----------------------------------+
|           Lyceum Core             |   |              nomos               |
| (ローカル & リモート LLM バックエンド) |   | (状態検証 & エージェント契約)    |
+-----------------------------------+   +----------------------------------+
          |
          v (テンソル演算)
+-----------------------------------+
|            LeanTensor             |
| (AVX-512 & 依存型カーネル)        |
+-----------------------------------+
```

### 2.2. Level 2: コンテナ構成 (Container Diagram)
- **`Pakila.Core.Machine`**: ステートマシン型メインループ。プロンプト履歴および状態更新を管理。
- **`Pakila.Core.Environment` / `TerminalEnv`**: CLI / 物理ターミナル入出力を抽象化する環境層。
- **`Pakila.Plugins`**: Wasmtime FFI 連携による動的プラグインサンドボックス。
- **`Pakila.Memory`**: VectorDB と埋め込みによる RAG コンテクスト検索エンジン。

### 2.3. Level 3: コンポーネント構成 (Component Diagram)
- **`Pakila.Tokenizer`**: Symbol32 準拠の日本語マルチバイト対応トークナイザ。
- **`Pakila.Plugins.Sandbox`**: Wasm 外部コード安全実行サンドボックス。
- **`Pakila.MainLoop`**: `nomos` のエージェント契約に従う決定論的状態遷移ループ。
- **`Pakila.Governance`**: MCP / スキルガバナンスおよび Vlog パーサー。
