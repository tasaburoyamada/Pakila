# ADR-002: Lyceum バックエンドとの透過的モナド接続

## ステータス
承認済 (Accepted)

## コンテキスト
Pakila はリモートの Gemini API 連携と、ローカル環境で動作する GGUF (Gemma 等) モデルの推論パイプラインの両方をサポートする必要がある。上位の実行エンジンが下層のバックエンド種別に依存しない抽象化が求められる。

## 決定
- `Lyceum` ライブラリの `LlmBackend` モナド・型クラスを包摂し、Pakila のモナドスタック内から透過的に LLM 推論を呼び出せるインターフェースを採用する。

## 帰結
- モデル切り替えやプロトコル変更に伴う Pakila コアロジック（`MainLoop` / `Machine`）の改修が不要となる。
- モデル非依存の汎用的堅牢性が静的型システムレベルで保証される。
