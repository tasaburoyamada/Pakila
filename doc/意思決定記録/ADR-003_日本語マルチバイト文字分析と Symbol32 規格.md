# ADR-003: 日本語マルチバイト文字分析と Symbol32 規格

## ステータス
承認済 (Accepted)

## コンテキスト
CLI およびトークナイザ層における日本語マルチバイト文字列処理において、バイト境界面の破壊、文字化け、切り出しエラーを物理的に防止する必要がある。

## 決定
- 文字コード表現および内部データ構造に `Symbol32` / UTF-8 バイト境界安全規格を採用し、全マルチバイト文字に対する安全な境界決定を静的に適用する。

## 帰結
- トークナイザ (`Pakila.Tokenizer`) やターミナル出力を扱うレイヤーにおいて、マルチバイト境界の切断による実行時例外を完全に排除。
