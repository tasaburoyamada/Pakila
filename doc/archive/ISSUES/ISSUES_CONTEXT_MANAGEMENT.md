# イシュー: トークンベースのコンテキスト管理と自動要約

## 概要
モデルのトークン上限を超える履歴（List Message）を管理するため、`tiktoken-rs` に相当するカウント機能および、LLM を利用した履歴要約機能の実装が必要。

## 詳細タスク
- [x] `src/Memory/TokenManager.lean`: `tiktoken` 互換トークン計算基盤の実装。
- [x] `src/Memory/ContextTruncator.lean`: コンテキストが制限を超えた際、どのメッセージを優先的に要約・削除するかの戦略的切り捨てロジック。
- [x] マルチトークン境界を考慮したセーフティなメッセージ切り詰め処理。
- [x] `src/Core/Summarizer.lean`: 履歴リストが上限を超えた際にトリガーされる、要約用プロンプト生成および LLM への要約要求ロジック。
- [x] 要約メッセージを履歴に統合する際の、元の会話状態の保持プロトコル（MainLoopにて統合）。
