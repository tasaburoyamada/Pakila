# イシュー: テスト用 LLM モックフレームワークの実装

## 概要
`lasada` のテストコード（`interpreter_test.rs`）は `MockLlm` を用いて、特定のユーザ入力に対して固定的な応答を生成し、エラー解析・修復エンジンの動作確認を行っている。`pakila` ではテスト実行基盤と統合可能なモックフレームワークが不足している。

## 詳細タスク
- [x] `test/Mock/LlmMock.lean`: 特定の入力に対して確定的な動作（例: ls コマンド要求には特定のbashコードを返す）を再現するテスト専用の LLM バックエンド実装。
- [x] テスト用シナリオ定義ファイル (`.json`) の読み込みとモック動作の動的設定機能。
