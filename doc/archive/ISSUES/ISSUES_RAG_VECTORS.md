# イシュー: RAG におけるメタデータ検索機能の精緻化

## 概要
`VectorDB` における類似度検索において、テキスト内容だけでなく、メタデータ（ソースファイル名、分類等）をフィルタリング条件として活用するための基盤が `pakila` にはない。

## 詳細タスク
- [x] `src/Memory/VectorDB.lean`: `HashMap String String` 形式のメタデータを用いた検索クエリフィルタリング機能の実装。
- [x] `cosine_similarity` 計算時の浮動小数点精度の確認と、類似度閾値の定数最適化。
- [x] インデックス構造の永続化形式（JSON）とメモリ内表現の変換ロジックの厳密化。
