# イシュー: @シンタックスによるインラインファイル内容展開

## 概要
`lasada` の `analyze_files` 関数は、ユーザー入力内の `@path/to/file` を検出し、その内容を自動的にプロンプトにインライン展開する。`pakila` ではこのパースと展開ロジックが未実装。

## 詳細タスク
- [x] `src/Core/FileInjector.lean`: 正規表現 `r"@([^\s]+)"` に相当するパースロジックを `Parsec` または正規表現で実装。
- [x] 検出されたパスに対し、ファイル読み込みを行い、`--- <path> ---\n<content>\n---` のフォーマットで注入する機能。
- [x] 読み込み失敗時のエラーハンドリング（無視、または警告の注入）。
