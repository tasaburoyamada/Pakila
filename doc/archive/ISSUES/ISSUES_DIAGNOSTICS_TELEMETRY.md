# イシュー: 実行時テレメトリと診断ログの実装

## 概要
`lasada` は `sysinfo` を使用した実行時リソース（CPU/Mem）の診断収集機能を持つ。`pakila` では物理リソースの使用状況を観測し、プロンプトへフィードバックする機能が欠如している。

## 詳細タスク
- [x] `src/Diagnostics/SysInfo.lean`: 実行プロセス単位のリソース使用状況の収集と監視。
- [x] `src/Core/PromptManager.lean`: 収集したシステム負荷情報をプロンプトへ注入し、計算リソースを意識した推論を促進するロジック。
- [x] 診断情報の定常的な可視化処理。
