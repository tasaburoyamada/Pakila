# Pakila vs Gemini CLI 0.43.0: UX Audit Matrix

本ドキュメントは、Pakila が Gemini CLI 0.43.0 と完全に同等の UI/UX を達成するための網羅的監査項目を定義し、その調査結果を記録したものである。

## 1. 起動・初期化 (Startup UX)
| 項目 ID | シナリオ | 監査ポイント | 判定基準 (Gemini 0.43.0) | 現状 (Pakila) |
| :--- | :--- | :--- | :--- | :--- |
| ST-01 | `gemini` (引数なし) | 画面遷移 | `\x1b[2J\x1b[3J\x1b[H` による完全クリア | 実装済 |
| ST-02 | 初期ロゴ | レイアウト | 256色コード 74, 110, 140, 139, 174 のグラデーション | 実装済 |
| ST-03 | バージョン/ステータス | 表示項目 | `Signed in with Google /auth`, `Plan: ... /upgrade` | 暫定実装済 (文言微修正要) |
| ST-04 | 重要通知 (Notice) | 枠線描画 | `38;5;229` (薄黄) の角丸 `╭─╮` ボックス | 未実装 |
| ST-05 | 初期化ログ | 非表示性 | 標準出力へのログは一切なし | 抑制済 |

## 2. 入力インターフェース (Input Layer)

| :--- | :--- | :--- | :--- | :--- |
| IN-01 | プロンプト記号 | 形状と色 | `❯ ` (Cyan) + 末尾に半角スペース1つ | 実装済 |
| IN-02 | 入力履歴 (History) | 永続化 | `~/.gemini/history` 等への保存と上下キー呼び出し | 未実装 |
| IN-03 | カーソル操作 | 編集機能 | `readline` 相当の emacs keybind (Ctrl+A/E/F/B) | 未実装 |
| IN-04 | 巨大ペースト | レンダリング | ペースト中のチラつき防止と正しい改行処理 | 未検証 |
| IN-05 | タブ補完 | ファイルパス | `@` 入力時のパス補完候補表示 | 未実装 |

## 4. 実行・ツール演出 (Execution Layer)
