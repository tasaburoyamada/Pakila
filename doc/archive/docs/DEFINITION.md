# Project: Pakila (Lean 4 / Formalized Architecture)

Open-Interpreter および `lasada` を極限まで進化させ、Lean 4 による数理的検証と HV-CAD による自律的制御を融合させた、世界初の「証明可能な自律型インタプリタ」。

## 1. 目的
- **数理的検証による信頼性の確立**: 実行エンジンの状態遷移やインタプリタの停止性を Lean 4 の型システム上で定義し、自律エージェントの暴走や矛盾を構造的に排除する。
- **HV-CAD (Human-Value Centric Autonomous Development) の深化**: AI を「確率分布の操作対象」として厳格に管理し、`.vlog` 形式の高密度トークン・ベクトルを用いて、人間の価値判断を数学的精度で実行プロセスへ同期させる。
- **Any-To-Any マルチモーダル対応**: テキスト、画像、音声、動画、ファイルをシームレスに扱う多相的メッセージ構造を備え、Gemini API 等の最新マルチモーダルモデルの能力をフルに引き出す。

## 2. 建築原則 (Architectural Principles)
- **検証先行 (VFR - Verification First Runtime)**: 実装の前に「正解の事実」を定義し、Lean カーネルによる検証を経たロジックのみを実行環境へデプロイする。
- **環境界面の物理的堅牢化**: 「Lean にバグは無いが環境との界面にはバグが潜む」という洞察に基づき、OS コマンド、I/O、ネットワーク通信に対して徹底的な防弾仕様（リミッター、例外捕捉、物理チェック）を施す。
- **自律実行ループ (Autonomous Loop)**: 思考、実行、フィードバック、自己修復のサイクルを再帰的に定義し、人間が介在することなくタスクを完遂する実効性を確保する。

## 3. 技術目標 (Technical Goals)
- **Lean 4 によるコア実装**: 純粋関数型言語としての副作用分離、依存型を利用した不変条件の記述、および FFI による低レベル操作の安全なラップ。
- **ハイブリッド・モデル発見**: クラウド API（Gemini）とローカルモデル（GGUF/mmproj）を統合管理し、環境に応じて最適な推論リソースを自律的に選択する。
- **原子的な状態永続化**: セッション情報の JSON シリアライズと復元を全階層で実装し、不慮の停止時でも作業コンテキストを完全に保護する。
