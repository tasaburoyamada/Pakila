# ネイティブ最適化：AVX-512 自動生成

Pakila と LeanTensor は、Lean 4 のメタプログラミング機能を駆使して、物理限界の計算速度を実現しています。

## #compile_native マクロ
私たちは、行列演算（MatMul）の数学的定義から、直接最適化された C コードを生成するカスタムマクロを実装しました。
- **SIMD 活用**: Intel AVX-512 命令セットをターゲットにし、512ビット幅のレジスタ（zmm）を一度に回します。
- **FMA パス**: Fused Multiply-Add 命令 (`_mm512_fmadd_pd`) を自動適用し、積和演算を単一サイクルで実行します。

## ユニバーサル・フォールバック
最高速度を追求しつつ、互換性も犠牲にしません。
- **動的検知**: 実行時に CPUID を確認し、AVX-512 が利用不可な場合は自動的に汎用 C カーネルへ切り替えます。
- **二重の安全性**: ネイティブ実行が失敗した場合でも、ピュア Lean による数理演算コードが最後の砦として機能します。

## Lake 統合
生成されたネイティブコードは、Lake ビルドプロセスによって自動的にコンパイル、リンクされます。ユーザーは特別な外部ツールを用意することなく、`lake build` を叩くだけで最高性能のバイナリを手にすることができます。
