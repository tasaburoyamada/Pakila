# 100% Pure Lean 4 推論エンジン

Pakilaは、推論の全工程を Lean 4 で完遂する「ピュア・エンジン」を搭載しています。

## 外部依存からの脱却
以前のバージョンでは Rust の `candle` ライブラリを使用していましたが、これを完全に廃止しました。理由は以下の通りです：
1. **ビルドの不確実性**: Rust コンパイラのバージョンや C++ の共有ライブラリのリンクエラーにより、実行環境が不安定になることを防ぐため。
2. **境界の不透明性**: FFI 境界を越える際、数学的な証明が途切れてしまうことを嫌い、メモリ管理からビット演算までを Lean の統治下に置くため。

## 実装されたピュア・コンポーネント
- **GGUFパーサー**: `ByteArray` から直接ヘッダー、メタデータ、テンソル情報をパースします。
- **デクオンタイザー**: Q4_0 (4bit) などの量子化ビット列を、Lean の純粋関数内で Float 配列へ展開します。
- **Base64**: マルチモーダル・プロトコルに必要な変換を、外部コマンドなしで自作実装しています。
- **システム情報**: `/proc` ファイルシステムを直接読み取り、自らのリソース状況を把握します。

## 物理加速へのブリッジ
ピュアな Lean 4 コードは、コンパイル時に自己生成された AVX-512 カーネルへと安全に「昇華」されます。これにより、ピュアな論理性を保ったまま、ネイティブ C++ を凌駕する速度を実現します。
