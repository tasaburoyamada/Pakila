# イシュー: デリミタを用いた正確なコマンド終了検知 (Bash)

## 概要
`lasada` の `bash_executor.rs` は、コマンドの終了を検知するために `echo "__LASADA_END_<ID>_<TIMESTAMP>__:$?"` という独自のデリミタを使用し、その終了ステータス (`$?`) を取得している。`pakila` では単純な `wait` のみが行われており、出力ストリームとの同期が不十分。

## 詳細タスク
- [x] `src/Plugins/Bash.lean`: コマンド実行の末尾に一意なデリミタを付与するロジックの実装。
- [x] `stdout` ストリームを監視し、デリミタを検出した瞬間に読み取りを停止・終了コードを抽出するステートマシンの実装。
- [x] `exec 2>&1` による標準エラー出力の統合制御。
- [x] 30秒のハードタイムアウト制御とプロセス強制終了の安全性証明。
