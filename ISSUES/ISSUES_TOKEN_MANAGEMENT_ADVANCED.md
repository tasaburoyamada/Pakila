# イシュー: トークン制限と正確なコンテキスト管理

## 概要
`lasada` はモデルごとのトークン制限を正確に把握し、要約プロセスを行っているが、`pakila` ではこのコンテキスト管理のロジックが未定義。

## 詳細タスク
- [x] `src/Memory/TokenCounter.lean`: 各 LLM バックエンドのモデル特性に基づいたトークン数算出。
- [x] `src/Memory/ContextTruncator.lean`: コンテキストが制限を超えた際、どのメッセージを優先的に要約・削除するかの戦略的切り捨てロジック。
- [x] マルチトークン境界を考慮したセーフティなメッセージ切り詰め処理。
