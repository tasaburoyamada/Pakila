# イシュー: 依存パッケージの完全な移植とビルド検証

## 概要
`lasada` の `Cargo.toml` には、`reqwest`, `serde`, `tokio`, `candle-core`, `tokenizers` 等、多くの外部クレートが存在する。`pakila` においてこれらを Lean 4 の `lake` 環境下で完全に依存解決し、コンパイルを通す必要がある。

## 詳細タスク
- [x] `lakefile.toml`: 上記ライブラリと同等の Lean パッケージへのマッピングと依存関係定義。
- [x] C++ ライブラリ（`candle` 等）のリンクおよびコンパイル設定の確立。
- [x] ビルド検証：依存関係が解決された状態での全モジュールコンパイルの確認。
