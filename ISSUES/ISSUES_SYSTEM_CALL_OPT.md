# イシュー: システムコール処理の低レイヤー最適化

## 概要
`lasada` の Bash 実行基盤は単純な `tokio::process` を利用しているが、高い負荷条件下ではシステムコールのオーバーヘッドとバッファリングがボトルネックとなる。`pakila` では低レイヤーでの最適化が未実装。

## 詳細タスク
- [x] `src/Plugins/SysCallOptimizer.lean`: 頻出システムコール（read/write/wait）に対するカスタムバッファ管理と、不要なコンテキストスイッチを抑制する最適化モジュール。
- [x] 非同期入出力におけるゼロコピー実装の検討と Lean 上での安全性検証。
