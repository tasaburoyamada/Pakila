# イシュー: ビルド環境と依存ライブラリ管理の保守

## 概要
`PREREQUISITES.md` に記載されている環境要件（システムライブラリ、Rust ツールチェーン等）を `pakila` に移植し、環境構築を自動化・検証可能にする。

## 詳細タスク
- [x] `scripts/check_prereqs.sh`: システム環境が `pakila` の動作条件（`ffmpeg`, `xdotool`, 等）を満たしているか検証するスクリプトの実装。
- [x] `lakefile.toml` への依存ライブラリバージョンの固定と、ビルドキャッシュ戦略の策定（Lean 標準機能の活用）。
