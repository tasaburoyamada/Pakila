# イシュー: CLI サブコマンド構造と引数パースの厳密化

## 概要
`lasada` の `clap` 定義には、`debug` フラグ、モデル指定、API エンドポイント、プロンプト上書き、自動実行モード、セッション管理など、複雑なフラグ処理がある。これらを Lean の型システムで厳密に定義する必要がある。

## 詳細タスク
- [x] `src/CLI/Args.lean`: サブコマンド（インタラクティブ/セッション管理）とオプションフラグの階層構造を型安全に定義。
- [x] フラグ相互排除（例: --model と --base_url は特定のバックエンドでのみ有効）の検証ロジック。
