# イシュー: ベクトルデータベースと埋め込み生成基盤の未実装

## 概要
`lasada` は `fastembed` ライブラリを使用してテキストの埋め込みベクトルを生成し、ローカルに永続化する `VectorDB` を備えている。`pakila` にはこの機能がない。

## 詳細タスク
- [x] `src/Memory/Embedding.lean`: `fastembed` に相当する埋め込みベクトル生成基盤の Lean ラッパーまたは実装。
- [x] `src/Memory/VectorDB.lean`: ベクトルデータ（`VectorEntry`）のシリアライズ・保存およびコサイン類似度を用いた検索機能の実装。
- [x] 検索スコアの閾値判定（現在は 0.5 固定）および上位K件の抽出ロジックの実装。
